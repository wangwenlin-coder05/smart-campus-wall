## 📋 建议方案

### 方案A：渐进式迁移（推荐）

**优点**：
- 不影响现有代码运行
- 可以逐步验证新架构
- 风险可控

**步骤**：
1. 保留`com.wwl.entity`包不变
2. 新开发的模块使用`com.wwl.model`三层架构
3. 逐步迁移旧代码到新架构
4. 全部迁移完成后删除旧包

### 方案B：立即全面切换

**优点**：
- 一次性完成重构
- 架构统一

**缺点**：
- 需要修复所有编译错误
- 风险较高
- 需要大量测试

1. 修复OrderInfoServiceImpl中的图片列表获取逻辑
2. 修复WallPostServiceImpl中的所有类型不兼容问题
3. 检查其他Service实现类是否有类似问题
4. 全面测试所有接口

### 1. 修复OrderInfoServiceImpl

**问题**：Entity中删除了`orderImageList`字段

**解决方案**：
```java
// 修改前
List<String> orderImageList = orderInfo.getOrderImageList();

// 修改后 - 从数据库查询
List<OrderImage> images = orderImageMapper.selectByOrderId(orderInfo.getId());
List<String> orderImageList = images.stream()
    .map(OrderImage::getImageUrl)
    .collect(Collectors.toList());
```
